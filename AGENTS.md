# Project agent instructions

- Read **README.md** and **docs/AGENT-HANDOFF.md** before planning work.
- Preserve the permanent documentation structure and update the affected canonical documents in place.
- WishUBest is a multilingual doctor discovery, appointment booking, and medical consultation platform; do not use generic marketplace vocabulary.
- Do not scaffold an application, create migrations, install dependencies, or implement product features until the documented decision gates are satisfied.
- After each commit, update **docs/PROJECT-STATE.md** so it identifies that commit; keep the state file in the same commit when possible.
- Do not make open provider choices (video, realtime, translation, payments, hosting, cloud, storage, messaging, email/SMS) by implication. Document an evaluation and a decision record first.
- Create a decision record for materially architecture-affecting choices using the existing required headings and status vocabulary.
